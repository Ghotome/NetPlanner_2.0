# Network Planner

Network Planner — кросплатформений застосунок для проєктування та візуалізації IP‑мереж на реальній мапі. Він допомагає інженеру швидко розмістити сайти, об’єднати їх лінками, оцінити покриття і видимість (LOS), зберігати проєкти та виконувати базовий моніторинг.

Навіщо це потрібно:
- планування мережі на реальній географії (OSM) з топологією поверх мапи;
- аналіз рельєфу (DEM) і підказки для підняття антен;
- візуалізація зон покриття секторних/напрямних антен;
- ведення структури сайту з пристроями і лінками;
- збереження/відкриття проєктів і швидкий доступ до обладнання (WebFig/SSH).
- альтернатива застарілим Radio Mobile, складним у використанні (але точним) QGIS та інтеграція базових інструментів для моделювання мережі в одному додатку. 

Стек: PySide6 + Qt WebEngine + Leaflet (OSM).
