Network Planner — опис доступного функціоналу

Застосунок дозволяє створювати проєкти мережі на мапі. Ви можете додавати сайти (CORE/POP/CPE), керувати їхніми параметрами антени та одразу бачити сектор покриття. Для кожного сайту доступні параметри: азимут, сектор, підсилення, висота антени, частота, потужність TX, RX gain, RX height, RX sensitivity, втрати та margin. Зміни застосовуються через кнопку “Застосувати антену”.

Лінки між сайтами створюються через контекстне меню сайту: ПКМ по сайту → “Створити лінк” → вибір цільового сайту ЛКМ. У діалозі лінку задаються тип, параметри, назва та нотатки. Лінки видно на мапі та в дереві проєкту, можна видаляти або перейменовувати.

Для кожного сайту є менеджер пристроїв (подвійний по сайту). У менеджері можна додавати пристрої, задавати IP, тип, нотатки і порти. Порти додаються окремо для Web/SSH/SNMP. Через контекстне меню пристрою доступні відкриття WebFig/SSH, позначення uplink та видалення пристрою. Є також лінки між пристроями; їх можна створювати перетягуванням портів і видаляти через ПКМ на лінії.

Покриття відображається на мапі (можна вимкнути/увімкнути в меню “Вигляд”). При побудові враховуються параметри антени, RX sensitivity, втрати, margin, RX gain та рельєф (DEM/LOS). Для LOS доступний окремий інструмент: меню “Інструменти → LOS”, далі вибір двох точок ЛКМ — відкривається профіль траси та статус видимості.

Є інструмент “Визначити висоту”: після увімкнення в меню “Інструменти” при наведенні на мапу показується висота точки. 
Також є калькулятор EIRP у окремому вікні, який показує FSPL, потрібний і фактичний EIRP, а також OK/НЕ ОК з поясненнями формул.
