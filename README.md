# Network Planner

Network Planner — кросплатформений застосунок для проєктування й візуалізації IP‑мереж на реальній карті. Він об’єднує планування сайтів, радіорозрахунки покриття, аналіз рельєфу та базовий моніторинг у єдиному робочому інтерфейсі.

## Для чого цей застосунок
- швидке моделювання мережі поверх карти OSM;
- побудова топології між сайтами;
- оцінка видимості, радіогоризонту та зон покриття;
- робота з рельєфом та висотами (DEM);
- базовий моніторинг доступності пристроїв.

## Основні можливості

### 1) Проєкти та структура
- створення, збереження й відкриття проєктів;
- дерево проєкту з сайтами та лінками;
- автозбереження у фоні.

### 2) Сайти
- розміщення сайтів на мапі та редагування атрибутів;
- параметри сайту: тип, координати, висота, середовище;
- керування антенами на сайті (тип, азимут, сектор, підсилення, висота).

### 3) Лінки між сайтами
- створення лінків між сайтами;
- типи лінків (PtP / PtMP);
- налаштування частоти, потужності, ширини каналу та параметрів антен.

### 4) Рельєф і висоти (DEM)
- відображення шару висот та легенди;
- отримання висоти точки для сайту;
- використання рельєфу в радіорозрахунках.

### 5) Покриття та радіомодель
- візуалізація зон покриття секторних і напрямних антен;
- розрахунок покриття з урахуванням:
  - LOS та дифракції;
  - радіогоризонту (з запасом на очікувану дифракцію);
  - рельєфу місцевості;
  - середовища (відкрите, змішане, міське, висока рослинність);
  - ширини каналу та чутливості приймача.
- растрове покриття з «острівцями» сигналу та «сліпими зонами».

### 6) LOS / профіль лінку
- аналіз прямої видимості між сайтами;
- профіль висот уздовж траси;
- підказки щодо підняття антен.

### 7) Моніторинг
- автоматична перевірка доступності пристроїв;
- статуси UP/DOWN/DEGRADED на мапі;
- журнал подій і панель проблемних вузлів.

### 8) Доступ до обладнання
- швидке відкриття WebFig/SSH із інтерфейсу сайту;
- врахування вказаних IP та портів.

## Як користуватись

### 1) Створення проєкту
- **Файл → Новий проєкт**.
- Додай сайти через **ПКМ на мапі → Створити сайт**.

### 2) Налаштування сайту
- Клік по сайту відкриває панель інспектора.
- Задай висоту, тип, параметри антен і середовище.

### 3) Лінки між сайтами
- Увімкни **Інструменти → Додати лінк**.
- Перетягни лінію між двома сайтами та задай параметри лінку.

### 4) Покриття та рельєф
- Увімкни **Вигляд → Шар висот** для аналізу рельєфу.
- Увімкни **Вигляд → Покриття** для перегляду зон покриття.

### 5) LOS / профіль
- Для PtP лінків відкрий інструмент LOS і переглянь профіль траси.

### 6) Моніторинг
- Додай IP та порт пристроїв.
- Моніторинг оновлює статуси автоматично.

## Примітка
Проєкт створений як практичний інженерний інструмент для швидкого планування та перевірки гіпотез.
