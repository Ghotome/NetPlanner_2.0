# Changelog

## [0.10.0] - 2026-01-27
### Added
- Доступ до обладнання із контекстного меню пристроїв (WebFig/SSH) для швидкого переходу до керування.
### Changed
- WebFig відкривається з урахуванням порту з поля пристрою, щоб не вводити URL вручну.

## [0.9.0] - 2026-01-27
### Added
- Моніторинг доступності (PingChecker) з періодом 1 c та статусами UP/DOWN/DEGRADED.
- Візуальна індикація статусів на мапі (кольори маркерів) і у сайті.
- Панель моніторингу з відсотком доступності, списком проблемних і журналом подій.
- Режим ручного виставлення статусів пристроїв для тестування.
### Changed
- Логіка статусу сайту: DOWN якщо uplink пристрій DOWN; DEGRADED якщо uplink UP, але є DOWN пристрої; UP якщо всі UP.
### Fixed
- Узгоджено відображення статусів між мапою, деревом і інспектором.

## [0.8.0] - 2026-01-27
### Added
- Збереження/завантаження проєкту у форматі .netproj (JSON) зі schema version.
- Автозбереження і діалог підтвердження перед закриттям, щоб уникати втрати даних.
### Changed
- Серіалізація/десеріалізація охоплює сайти, пристрої, лінки, антени, статуси та позиції.

## [0.7.0] - 2026-01-27
### Added
- Секторні “пелюстки” покриття для POP/CORE/CPE з параметрами антени (тип, азимут, сектор, gain).
- Візуалізація покриття на мапі (геодезичні полігони).
- DEM-обмеження для покриття (кліпінг за рельєфом) як підготовка до якісних розрахунків.
### Changed
- Атрибут “висота антени” перенесено на рівень сайту для єдиного використання у покритті та LOS.

## [0.6.0] - 2026-01-27
### Added
- Модуль LinkAnalyzer: профіль висот між сайтами, оцінка LOS, розрахунок рекомендованого підняття антени.
- Окреме вікно з графіком профілю висот для PtP.
### Changed
- Врахування висоти антени сайту при LOS, щоб результати були ближчими до реальних.

## [0.5.0] - 2026-01-27
### Added
- Оверлей висот (DEM) з кешуванням тайлів і перемиканням шару.
- Легенда висот (метри) та відображення висоти в інспекторі.
### Changed
- Кешування тайлів по видимій області і зуму для швидкості роботи.
- Повернуте класичне забарвлення тайлів (зелений – високі, червоний – низини) і синхронізовано з легендою.

## [0.4.0] - 2026-01-27
### Added
- Лінки між сайтами з різними типами (PtP/PtMP/Ethernet) і кольорами.
- Рисування лінків “drag-line” як на мапі, так і всередині сайту.
- Підпис типу лінка на мапі та в сайті, щоб одразу було видно тип з’єднання.
- Контекстні діалоги створення лінку з атрибутами для wireless/ethernet.
### Changed
- Логіка вибору атрибутів лінка: показ лише релевантних полів за типом.
### Fixed
- Виправлена робота Ethernet-лінків та відображення їхніх атрибутів.

## [0.3.0] - 2026-01-27
### Added
- Вбудована мапа Leaflet у Qt WebEngine з OSM Standard тайлами.
- Додавання/переміщення сайтів на мапі, синхронізація з деревом.
- Підказки по назві сайту при наведенні курсора.
### Changed
- Перехід на CDN Leaflet для стабільного завантаження.
### Fixed
- Виправлення інтеграції Qt WebEngine і доступу до Leaflet.

## [0.2.0] - 2026-01-27
### Added
- Доменно-об’єктна модель (проєкт, сайт, пристрій, лінк, статуси, антени).
- UI-скелет: основне вікно, дерево проєкту, інспектор.
- Діалог сайту з графічною схемою пристроїв і drag‑&‑drop позиціонуванням.
- Створення пристрою через контекстне меню з формою атрибутів і notes.
### Changed
- Менеджмент сайту відкривається по подвійному кліку (UX без випадкових відкриттів).
- Позиції пристроїв зберігаються між редагуваннями (без скидання).
### Fixed
- Підказки з нотатками відображаються з затримкою 1.5 c (спочатку ім’я, потім notes).

## [0.1.0] - 2026-01-27
### Added
- Базова структура репозиторію, документація, стартова конфігурація.
- Мінімальне PySide6-вікно для перевірки запуску.
