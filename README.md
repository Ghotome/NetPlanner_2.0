# Network Planner

Network Planner — кросплатформений застосунок для проєктування та візуалізації IP‑мереж на реальній мапі. Він допомагає інженеру швидко розмістити сайти, об’єднати їх лінками, оцінити покриття і видимість (LOS), зберігати проєкти та виконувати базовий моніторинг.

Навіщо це потрібно:
- планування мережі на реальній географії (OSM) з топологією поверх мапи;
- аналіз рельєфу (DEM) і підказки для підняття антен;
- візуалізація зон покриття секторних/напрямних антен;
- ведення структури сайту з пристроями і лінками;
- збереження/відкриття проєктів і швидкий доступ до обладнання (WebFig/SSH).
- альтернатива застарілим Radio Mobile, складним у використанні (але точним) QGIS та інтеграція базових інструментів для моделювання мережі в одному додатку. 

Стек: PySide6 + Qt WebEngine + Leaflet (OSM).

## Як користуватись (короткий гайд)

### 1) Створення проєкту
- Меню **Файл → Новий проєкт**.
- Додай сайти через **ПКМ на мапі → Створити сайт**.
- Після створення сайт з’явиться на мапі і в дереві проєкту.

### 2) Менеджмент сайту (пристрої всередині)
- Подвійний клік по сайту в дереві або на мапі — відкриється менеджмент сайту.
- У вікні сайту:
  - **ПКМ по схемі → Додати пристрій**.
  - Заповни атрибути пристрою і notes.
  - Перетягуй пристрої для зручного розташування.
  - Малюй лінки між пристроями від точки до точки.

### 3) Лінки між сайтами
- Увімкни **Інструменти → Додати лінк**.
- Перетягни лінію між двома сайтами на мапі.
- У діалозі вкажи тип лінку та атрибути.

### 4) Інспектор (панель праворуч)
- Клік по сайту або лінку показує їх атрибути.
- Доступне редагування полів з валідацією.
- Поля змінюються динамічно залежно від типу об’єкта.

### 5) Висоти (DEM) і легенда
- Увімкни **Вигляд → Шар висот**.
- З’явиться heatmap висот і легенда.
- В інспекторі для сайту відображається висота точки.

### 6) LOS / Профіль лінку
- Для PtP лінків доступний аналіз LOS.
- Показує профіль висот і рекомендації щодо підняття антени.

### 7) Покриття антен
- Для POP/CORE/CPE можна задати параметри антени (тип, азимут, сектор, gain, висота).
- Увімкни **Вигляд → Покриття** щоб бачити “пелюстки” на мапі.

### 8) Моніторинг
- Запусти моніторинг (вмикається автоматично).
- Статуси UP/DOWN/DEGRADED відображаються на мапі.
- Панель моніторингу показує проблемні вузли й журнал подій.
- Для тестів можна вручну задати статус пристрою.

### 9) Збереження/завантаження
- **Файл → Зберегти / Зберегти як** — файл `.netproj`.
- Автозбереження працює у фоні.

### 10) Доступ до обладнання
- У менеджменті сайту: **ПКМ по пристрою → Відкрити WebFig / Відкрити SSH**.
- WebFig враховує порт з поля пристрою.
